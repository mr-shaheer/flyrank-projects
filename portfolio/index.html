Principles

How I Work

Design patterns and engineering habits I apply to every multi-agent system.

  • 01

    Supervisor → specialist patterns over one giant prompt. I break complex tasks into discrete agents with clear handoffs, not monolithic prompts that try to do everything.

  • 02

    Guardrails on every input before an agent ever sees it. Input validation, jailbreak checks, and schema enforcement happen at the boundary, not inside the model.

  • 03

    Deterministic code for anything that needs to be correct - scoring, ranking, pricing - not left to the model's vibes. LLMs handle ambiguity; code handles precision.

  • 04

    Graceful degradation: live API → cache → offline fallback, so nothing dead-ends. Every external dependency has a backup plan.
