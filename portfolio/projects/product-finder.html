Case Study

Product Finder

Multi-agent shopping assistant with explainable scoring. Two agents hand off based on confidence; a hand-written algorithm ranks products transparently.

OpenAI Agents SDK Google Gemini SerpApi Pydantic v2 SQLite

Overview

Product Finder turns a plain-English request like "wireless headphones under $80" into a ranked, reasoned shortlist of real products. Instead of one model doing everything, an Orchestrator agent classifies intent — and if it isn't confident, it asks a clarifying question instead of guessing — then hands off to a Recommender agent that searches and ranks. The key design choice: scoring is not left to the LLM. A hand-written algorithm blends relevance, price fit, and budget detection into a transparent, reproducible score.

Architecture

What's Technically Interesting

  • Confidence-gated handoff: the agent knows when it doesn't know, and asks rather than guessing.
  • Resilient fetch pipeline - cache, then live API, then a built-in offline catalog - so the assistant never dead-ends even with no API key.
  • Every object crossing an agent/tool boundary is a validated Pydantic model.
  • Two different model tiers used deliberately: a cheap fast model for classification, a stronger one for the recommendation writeup.
