Case Study

Repro Tracker

Bug-report agent that reproduces bugs in a live sandbox. Reads a bug report, spins up an isolated browser, and returns a verdict with evidence.

OpenAI Agents SDK E2B Sandbox Playwright SQLite

Overview

Half of every bug backlog is unreproducible noise - engineers burn a morning just confirming a bug is real before anyone starts fixing it. Repro Tracker automates that step: you describe a bug, a Triage Agent parses it into a structured report, and a Reproduction Specialist spins up a real, isolated E2B sandbox, runs curl checks and Playwright browser automation against the actual URL, and returns a verdict - REPRODUCED, NOT REPRODUCED, or PARTIAL - with evidence like console logs and HTTP status codes attached.

Architecture

What's Technically Interesting

  • Actually executes the repro steps in a live sandboxed browser instead of asking an LLM to reason about whether a bug "sounds real."
  • Human-in-the-loop approval gate before any potentially destructive command runs.
  • Persistent SQLite sessions retain the last 16 messages of context per conversation.
