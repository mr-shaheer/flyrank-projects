Case Study

Agentic Researcher

Autonomous research pipeline: plan → search → write.
Three specialized agents orchestrated by a supervisor with dual entry points.

OpenAI Agents SDK Google Gemini Tavily Search API FastAPI ChatKit Pydantic Settings

Overview

Agentic Researcher takes a single topic and returns a fully structured, cited research report without further input. It's not one big prompt — it's three specialized agents that pass work down a pipeline: a Planner that breaks the topic into a research strategy, a Researcher that hits the live web via Tavily, and a Writer that synthesizes everything into a clean markdown report. A central supervisor built on the OpenAI Agents SDK orchestrates the handoffs, running on Google Gemini through Gemini's OpenAI-compatible endpoint.

Architecture

What's Technically Interesting

  • Two entry points (CLI + a FastAPI/ChatKit web server) drive the same agent graph - no duplicated logic.
  • Input guardrails run identically in both the CLI and web UI, and rejections surface as a normal chat message instead of a crash.
  • Conversation state persists via a shared SQLite session across both interfaces.
  • Runs entirely on free-tier APIs (Gemini + Tavily) - zero cost to operate.
